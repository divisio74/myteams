1. Server welcome

Description:
When the server accepts a new client connection, it sends a welcome response.

Response:
220 Service ready for new user. [CRLF]

--------------------------------------------------

2. Commands

2.1 /login

Description:
Authenticate a user and return its UID.

Request:
/login <username> [CRLF]

Response:
200 <uid> [CRLF]

Errors:
500 Internal server error [CRLF]
501 Syntax error in parameters or arguments. [CRLF]

--------------------------------------------------

2.2 /logout

Description:
Logout the current user.

Request:
/logout [CRLF]

Response:
200 <uid> [CRLF]

Errors:
300 User not logged in [CRLF]
500 Internal server error [CRLF]

--------------------------------------------------

2.3 /users

Description:
List all users.

Request:
/users [CRLF]

Response:
200 [
  <username1> <uid1>,
  <username2> <uid2>
] [CRLF]

Errors:
500 Internal server error [CRLF]

--------------------------------------------------

2.4 /user

Description:
Get information about a specific user.

Request:
/user <uid> [CRLF]

Response:
200 <username> <uid> [CRLF]

Errors:
400 User not found [CRLF]
500 Internal server error [CRLF]
501 Syntax error in parameters or arguments. [CRLF]

--------------------------------------------------

2.5 /send

Description:
Send a private message to another user.

Request:
/send <receiver_uid> <message_body> [CRLF]

Response:
200 [CRLF]

Errors:
300 User not logged in [CRLF]
400 User not found [CRLF]
500 Internal server error [CRLF]
501 Syntax error in parameters or arguments. [CRLF]

--------------------------------------------------

2.6 /messages

Description:
List all messages exchanged between the current user and another user.

Request:
/messages <other_uid> [CRLF]

Response:
200 [
  <sender_uid> <message_body>
  <sender_uid> <message_body>
] [CRLF]

Errors:
300 User not logged in [CRLF]
400 User not found [CRLF]
500 Internal server error [CRLF]
501 Syntax error in parameters or arguments. [CRLF]

--------------------------------------------------

2.7 /create

Description:
Create a new team. The current user becomes the team creator and is
automatically subscribed to the team. The server returns the uid of
the newly created team so the client can reference it later.

Request:
/create <team_name> <team_description> [CRLF]

Response:
200 <team_uid> [CRLF]

Errors:
300 User not logged in [CRLF]
500 Internal server error [CRLF]
501 Syntax error in parameters or arguments. [CRLF]

--------------------------------------------------

3. End of line rule

All messages exchanged between client and server are terminated by CRLF.
That means every request and every response must end with: \r\n (shown as [CRLF] above).
