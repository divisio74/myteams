1. Server welcome

Description:
When the server accepts a new client connection, it sends a welcome response.

Response:
220 Service ready for new user. [CRLF]

--------------------------------------------------

2. Commands

2.1 /login

Description:
Authenticate a user and return its UID.

Request:
/login <username> [CRLF]

Response:
200 <uid> [CRLF]

Errors:
500 Internal server error [CRLF]
501 Syntax error in parameters or arguments. [CRLF]

--------------------------------------------------

2.2 /logout

Description:
Logout the current user.

Request:
/logout [CRLF]

Response:
200 <uid> [CRLF]

Errors:
300 User not logged in [CRLF]
500 Internal server error [CRLF]

--------------------------------------------------

2.3 /users

Description:
List all users.

Request:
/users [CRLF]

Response:
200 [
  <username1> <uid1>,
  <username2> <uid2>
] [CRLF]

Errors:
500 Internal server error [CRLF]

--------------------------------------------------

2.4 /user

Description:
Get information about a specific user.

Request:
/user <uid> [CRLF]

Response:
200 <username> <uid> [CRLF]

Errors:
400 User not found [CRLF]
500 Internal server error [CRLF]
501 Syntax error in parameters or arguments. [CRLF]

--------------------------------------------------

2.5 /send

Description:
Send a private message to another user.

Request:
/send <receiver_uid> <message_body> [CRLF]

Response:
200 [CRLF]

Errors:
300 User not logged in [CRLF]
400 User not found [CRLF]
500 Internal server error [CRLF]
501 Syntax error in parameters or arguments. [CRLF]

--------------------------------------------------

2.6 /messages

Description:
List all messages exchanged between the current user and another user.

Request:
/messages <other_uid> [CRLF]

Response:
200 [
  <sender_uid> <message_body>
  <sender_uid> <message_body>
] [CRLF]

Errors:
300 User not logged in [CRLF]
400 User not found [CRLF]
500 Internal server error [CRLF]
501 Syntax error in parameters or arguments. [CRLF]

--------------------------------------------------

2.7 /create

Description:
Create a sub-resource depending on the current context set by /use.
- No context: create a team. The creator is automatically subscribed.
- Team context: create a channel in the current team.
- Channel context: create a thread in the current channel.
- Thread context: create a reply (message) in the current thread.

Request (no context - create team):
/create <team_name> <team_description> [CRLF]

Request (team context - create channel):
/create <channel_name> <channel_description> [CRLF]

Request (channel context - create thread):
/create <thread_title> <thread_body> [CRLF]

Request (thread context - create reply):
/create <reply_body> [CRLF]

Response (team created):
200 <team_uid> <team_name> <team_description> [CRLF]

Response (channel created):
200 <channel_uid> <channel_name> <channel_description> [CRLF]

Response (thread created):
200 <thread_uid> <creator_uid> <timestamp> <thread_title> <thread_body> [CRLF]

Response (reply created):
200 <thread_uid> <creator_uid> <timestamp> <reply_body> [CRLF]

Errors:
300 User not logged in [CRLF]
400 Team, channel or thread not found [CRLF]
500 Internal server error [CRLF]
501 Syntax error in parameters or arguments. [CRLF]

--------------------------------------------------

2.8 /subscribe

Description:
Subscribe the current user to a team. If the user is already subscribed,
the command succeeds without adding a duplicate.

Request:
/subscribe <team_uid> [CRLF]

Response:
200 [CRLF]

Errors:
300 User not logged in [CRLF]
400 Team not found [CRLF]
500 Internal server error [CRLF]
501 Syntax error in parameters or arguments. [CRLF]

--------------------------------------------------

2.9 /subscribed

Description:
List subscriptions. Has two modes depending on whether a parameter is given:
- With <team_uid>: list all users subscribed to the given team.
- Without parameter: list all teams the current user is subscribed to.

Request:
/subscribed [CRLF]
/subscribed <team_uid> [CRLF]

Response (without parameter - list of teams):
200 [
  <team_uid> <team_name>
  <team_uid> <team_name>
] [CRLF]

Response (with parameter - list of subscriber uids):
200 [
  <user_uid>
  <user_uid>
] [CRLF]

Errors:
300 User not logged in [CRLF]
400 Team not found [CRLF]
500 Internal server error [CRLF]

--------------------------------------------------

2.10 /unsubscribe

Description:
Unsubscribe the current user from a team. The user must be subscribed
to the team, otherwise the command returns an error.

Request:
/unsubscribe <team_uid> [CRLF]

Response:
200 [CRLF]

Errors:
300 User not logged in [CRLF]
400 Team not found or user not subscribed [CRLF]
500 Internal server error [CRLF]
501 Syntax error in parameters or arguments. [CRLF]

--------------------------------------------------

2.11 /use

Description:
Set the client context for context-dependent commands (/create, /list, /info).
The context determines which level of the hierarchy the client is operating on.
Without arguments, resets the context to the root level.

Request:
/use [CRLF]
/use <team_uid> [CRLF]
/use <team_uid> <channel_uid> [CRLF]
/use <team_uid> <channel_uid> <thread_uid> [CRLF]

Response:
200 [CRLF]

Errors:
300 User not logged in [CRLF]
400 Team, channel or thread not found [CRLF]

--------------------------------------------------

2.12 /list

Description:
List sub-resources depending on the current context set by /use.
- No context: list all teams the current user is subscribed to.
- Team context: list all channels in the current team.
- Channel context: list all threads in the current channel.
- Thread context: list all messages in the current thread.

Request:
/list [CRLF]

Response (teams):
200 [
  <team_uid> <team_name> <team_description>
  <team_uid> <team_name> <team_description>
] [CRLF]

Response (channels):
200 [
  <channel_uid> <channel_name> <channel_description>
  <channel_uid> <channel_name> <channel_description>
] [CRLF]

Response (threads):
200 [
  <thread_uid> <creator_uid> <timestamp> <thread_title> <thread_body>
  <thread_uid> <creator_uid> <timestamp> <thread_title> <thread_body>
] [CRLF]

Response (replies):
200 [
  <thread_uid> <sender_uid> <timestamp> <reply_body>
  <thread_uid> <sender_uid> <timestamp> <reply_body>
] [CRLF]

Errors:
300 User not logged in [CRLF]
400 Team, channel or thread not found [CRLF]
500 Internal server error [CRLF]

--------------------------------------------------

2.13 /info

Description:
Display details about the current resource set by /use.
Requires a context to be set (at least a team).
- Team context: show team uid, name and description.
- Channel context: show channel uid, name and description.
- Thread context: show thread uid, creator uid, timestamp, title and body.

Request:
/info [CRLF]

Response (team):
200 <team_uid> <team_name> <team_description> [CRLF]

Response (channel):
200 <channel_uid> <channel_name> <channel_description> [CRLF]

Response (thread):
200 <thread_uid> <creator_uid> <timestamp> <thread_title> <thread_body> [CRLF]

Errors:
300 User not logged in [CRLF]
400 Team, channel or thread not found [CRLF]
500 Internal server error [CRLF]
501 No context set [CRLF]

--------------------------------------------------

3. End of line rule

All messages exchanged between client and server are terminated by CRLF.
That means every request and every response must end with: \r\n (shown as [CRLF] above).
